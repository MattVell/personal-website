## Design Specificity Verdict

**LLM Assessment**: The current Hero section suffers from heavy category-interchangeability and unmistakable "AI Slop" patterns. The Plexus particle canvas background (floating dots connected by thin lines) and the glowing neon pill around the headline text ("design impecável") were heavily popularized by automated AI site builders and dark-mode templates. It lacks a strong visual anchor representing Mateus' actual craft (e.g., interactive UI preview card, code editor snippet, or authentic personal voice).

**Deterministic Scan**: `detect.mjs` completed with 0 warnings on `Hero.tsx`.

## Overall Impression
The section is clean and functional, but visually reads like a template generated by ChatGPT / v0 ("AI Slop"). Replacing abstract particle lines with a tangible UI visual anchor and replacing the headline pill badge with high-craft typography will instantly elevate it into a modern, bespoke portfolio.

1. **[P1] Canvas Plexus Background ("AI Slop" visual trope)**:

2. **[P1] Neon Pill Headline Badge ("design impecável")**:
